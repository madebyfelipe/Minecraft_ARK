   Espinossauro: peso 3 na água, 1 em planícies/taigas (`spawn.favored`).

  ~28 blocos). Começou depois da espreita (D27); causa não encontrada.

  desligada). Um worktree novo gera um mundo vazio e três testes de spawn falham: copie o `run/world` de um checkout
  que já tenha rodado.
- Sessões em segundo plano do Claude Code são **forçadas a trabalhar em worktree** e não podem rodar git no checkout
  principal (nem o `!` do usuário). Para atualizar o checkout do Felipe: `cd ~/Dev/Minecraft_ARK && git pull` no
  terminal dele.
- Arquivos de idioma: preserve o formato — `json.dumps(..., indent=2, ensure_ascii=False) + '\n'` reproduz o arquivo
  byte a byte.
- Assets do Revival são carregados em runtime e **nunca** copiados (D21); o `.mrpack` só leva o nosso jar.
